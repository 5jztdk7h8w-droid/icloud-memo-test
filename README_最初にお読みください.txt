iCloudメモ 同期テスト版

重要：
このテスト版は、端末ごとにブラウザ内へ一時保存し、JSONファイルの書き出し・読み込みでiCloud Driveを介してデータを受け渡す試作品です。
自動同期ではありません。iCloud Drive内のJSONをブラウザが直接・常時読み書きする仕組みではありません。

公開方法：
PWAとしてホーム画面追加するにはHTTPSで配信する必要があります。
このZIPを無料の静的ホスティング（例：GitHub Pages）に配置してください。
アプリ本体のファイルはホスティング先に置かれますが、メモの内容は送信されません。
個人情報・重要データはテストに使わないでください。

iPhone：
1. HTTPSの公開URLをSafariで開く
2. 共有ボタン → ホーム画面に追加
3. 「Webアプリとして開く」が表示された場合は有効にする
4. 起動してメモを登録
5. JSONを書き出す → 共有メニュー → ファイルに保存 → iCloud Drive

Mac：
1. HTTPSの公開URLをSafariで開く
2. Safariのメニュー「ファイル」→「Dockに追加」（対応macOS）
3. アプリを起動してメモを登録
4. JSONを書き出し、iCloud Driveフォルダへ移動

端末間の受け渡し：
1. 編集した端末で「JSONを書き出す」
2. 生成されたJSONをiCloud Driveに保存
3. もう一方の端末で「JSONを読み込む」
4. 読み込み時は現在の一覧がJSONの内容に置き換わります

注意：
・同時編集には対応しません。
・書き出し前にブラウザのデータを消すと、端末内の未書き出しデータを失う可能性があります。
・PWAのインストールにはHTTPS配信が必要です。
